# HSK 3.0 level 5

Ten narrative short stories with dialogue and real cultural or social content. Each one practises four
focus grammar points and brings back points from earlier stories. Words above level 5, names and
special terms are footnoted with pinyin and meaning. The plan and grammar map are in
[plans/hsk5-stories.md](../../plans/hsk5-stories.md).
